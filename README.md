# Company Bankruptcy Classification

Predict bankruptcy risk using financial indicators and machine learning classification models.

## What this project does
- Loads financial dataset
- Performs preprocessing + feature engineering
- Trains classification models to predict bankruptcy
- Evaluates with metrics (accuracy/F1/ROC-AUC)

## Tech stack
- Python, Pandas, NumPy
- scikit-learn
