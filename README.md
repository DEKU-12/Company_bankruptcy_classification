# Company Bankruptcy Classification

Predict whether a company is at risk of bankruptcy using financial indicators and machine learning classification models.

## Problem
Bankruptcy prediction helps investors, lenders, and businesses assess risk early using historical financial features.

## What I built
- Data preprocessing (missing values, encoding, scaling as needed)
- Baseline + multiple classification models
- Model evaluation using classification metrics
- Clear outputs (confusion matrix / ROC curve) for decision-making

## Tech stack
- Python
- Pandas, NumPy
- scikit-learn
- Matplotlib / Seaborn (if used)

## Repository structure
- `*.ipynb` — notebook(s) for EDA, modeling, evaluation
- `data/` — dataset (or instructions to download)
